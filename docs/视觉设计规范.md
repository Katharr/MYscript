# UI 3.0 视觉与布局规范

状态：用户确认的长期设计基准。正式 Qt 已实施首轮改造，但 Windows 真机反馈仍未达到视觉预期；以下包含 2026-11-13 已确认的修正方向，不能视为修正已实施或验收通过。

本文是视觉、尺寸和布局的唯一基准；基础需求见 [UI 3.0 规格](specs/21-ui-v3-spec.md)，本轮修正范围与验收见[真机视觉修正方案](specs/22-ui-v3-polish.md)，业务行为见[规格索引](specs/README.md)。HTML 原型是参考图，不是业务规则或生产组件。

## 1. 风格与主题

默认浅色：浅灰窗口与侧栏、白色工作区、蓝色主操作和选中态。以清晰的文字层级、细分隔线和小圆角表达层次。主要按钮集中在页面底部，辅助操作靠近对应对象。

内容使用连续列表与必要的功能分组。每行不单独悬浮，不叠加多层卡片、玻璃、发光或装饰渐变。阴影主要用于覆盖抽屉、弹窗等真实浮层。图标使用统一线性风格，允许任务图标采用低饱和底色。

本轮规定默认浅色，不增加主题切换入口、不设计新的深色方案；已有用户外观偏好仍按现有兼容策略处理。

## 2. 颜色令牌

由 Qt 主题层集中定义语义令牌。页面使用语义角色，避免逐页散写颜色；现有主题接口优先复用。

| 语义 | 3.0 色值 | 用途 |
| --- | --- | --- |
| 窗口 / 侧栏背景 | `#F3F4F6` | 主窗口底、导航 |
| 内容表面 | `#FFFFFF` | 主工作区、参数面板 |
| 辅助表面 | `#FAFBFD` | 日志背景、未选角色 |
| 正文 | `#202124` | 标题、标签、输入内容 |
| 次要文字 | `#68717D` | 次级状态、元信息 |
| 分隔线 | `#E4E7EB` | 区域与行分界 |
| 控件边界 | `#D8DCE1` | 普通按钮与输入框 |
| 主强调 | `#0067C0` | 开始、链接、勾选、焦点 |
| 主强调悬停 | `#005AA8` | 主操作悬停 |
| 强调色上文字 | `#FFFFFF` | 主按钮文字 |
| 导航选中背景 | `#E3EAF3` | 当前导航项 |
| 角色选中背景 / 边界 | `#F0F6FD` / `#ADCAE9` | 参与任务的角色 |
| 成功 | `#16794B` | 完成、成功 |
| 警告文字 / 背景 | `#996128` / `#FFF2DF` | 缺少标定、风险提示 |
| 危险 | `#BD343B` | 停止、确认破坏性操作、错误 |

颜色与文字共同表达状态。演练使用中性状态，实战以明确文字和警告色区分；红色保留给危险动作与错误。低对比度分隔线仅表达分组，控件仍需可辨识的边界、选中形状和键盘焦点。

## 3. 字体、间距与形状

以下为 100% 缩放下的逻辑像素参考，不是物理像素。Qt 按字体度量计算最小尺寸，系统缩放不再重复相乘；字号增大时控件随内容增长。

| 元素 | 参考值 |
| --- | --- |
| 字体 | Segoe UI / Microsoft YaHei UI，中文以实际可用字体回退 |
| 页面标题 | 25，半粗；紧凑窗口 23 |
| 任务名 / 功能组标题 | 14，中等字重 |
| 正文、表单、导航、关键状态 | 13 |
| 次要信息、时间 | 11–12；不承载唯一的错误或关键状态 |
| 页面左右 / 上下边距 | 24 / 20；紧凑窗口 16–20 |
| 相邻控件间距 | 8–12 |
| 内容块间距 | 12–16 |
| 常规输入控件高度 | 34–36 起点，依字体增长 |
| 底部主按钮高度 | 37 起点，依字体增长 |
| 日常任务行高 | 62；大窗口可增至 78 |
| 控件 / 面板圆角 | 5 / 7 |
| 工作区外壳圆角 | 左上 9，其余随原生窗口边界 |
| 线性图标 | 常规 16–20；任务图标约 21 |

原型中更小的时间、头像与徽标不作为正式 Qt 界面缩字的理由。保留已有复选框点击区域、输入控件可读性和表单宽度保障。长文本按可用宽度换行或省略，省略时提供全文；按钮使用短动作名。普通按钮（包括顶栏唤出、全关、日志）在静止状态即有清晰细边框，不依赖悬停才能辨认。字体清晰度独立验收：真机小字不得有明显缺笔或颗粒感，具体字体和渲染调整依据实测确定。

表单沿用已实施的交互：字段按名称、数值、路径等类型有界增长；数值控件保留原生范围、精度、键盘校验与增减提交行为。数值框和闭合下拉框即使获得焦点也不接受滚轮改值，滚轮交给页面滚动区；单位靠近数值，范围可放工具提示。滚动条保留原生命中、拖动与滚动逻辑，外观调整不缩小已有操作区域。

## 4. 全局布局

```text
左侧导航 | 路径             唤出 全关 日志 | 全局日志
         | 全局执行角色与队长选择         | 消息正文
         | 当前页面、参数或功能分组       | 消息正文
         | 执行摘要             开始/停止 | 急停入口
```

- 标准参考窗 1120×720，最小验收窗 800×640；既有窗口尺寸记忆继续生效。
- 导航参考宽 176；大窗口可用 190，紧凑窗口约 149。分为任务、管理两组，设置与关于置底。
- 导航选中态为淡蓝底、蓝色图标与左侧短指示线；文字与图标左对齐。
- 顶栏参考高 47。右侧按“唤出、全关、日志”顺序固定相邻，删除日志前装饰竖线，以间距和按钮边界区分；跨页面、日志收起或覆盖展开时都可达。同一日志按钮切换展开与收起，取消日志面板内重复的收起按钮。
- 唤出与全关使用既有窗口操作的对象范围、忙碌门禁和错误处理；全关须确认。移除单独的“窗口管理”菜单与重复入口。
- 日志位于右侧，与应用可布局的客户区同高，从顶部延伸到底部；不再从角色条下方开始。全局角色条位于左侧业务工作区。系统标题栏不属于日志内容区；全局状态栏如保留则位于左侧业务区，不缩短日志高度。
- 角色条采用紧凑的淡蓝选中态；复选框、角色名与等级、运行状态、互斥队长入口各自清晰。业务规则遵循统一选窗契约，原型中的示例头像、四角色数量及队长联动不是新业务要求。
- 页面标题、行首与底部摘要共用左边界。界面只出现控件名、状态和必要错误 / 安全提醒；不把设计理由或原理写成副标题。
- 底部执行栏固定在内容区，显示目标与模式摘要及一个开始 / 停止主操作；参数内容独立滚动。

## 5. 页面与组件

### 日常一条龙

使用一个连续清单，保留顺序、启用、任务名、模式、状态及配置入口。序号表达真实执行顺序，拖动与“调整顺序”作用于同一序列。任务名与状态可见，不能为日志降字号或删去业务列。

模式入口就近设置。演练项在真实执行序列中的跳过规则与各任务自身演练能力继续按既有业务区分，不因视觉改造统一成另一种含义。时间上限位于清单下方，启动与停止留在固定执行栏。

### 单项任务

任务选择使用横向标签页，顺序为宝图、运镖、秘境降妖、刷副本、秒装备。当前标签用蓝色文字与文字下方短细线标识；取消贯穿整排的粗长基线，选中线不延伸到标签左右内边距。标签切换同步更新参数、模式、标定信息及“开始任务名”；不同任务的配置各自保留。

标签支持鼠标、键盘焦点、左右方向键和 Home / End。空间不足时横向滚动标签，不改回下拉框；运行与停止期间锁定任务切换，停止动作始终可达。标签页承载原任务页面的完整业务能力，原型的两行占位面板不是功能删减依据。

### 通用工具

| 功能组 | 同组并排动作 |
| --- | --- |
| 队伍 | 一键组队、一键解散 |
| 背包 | 整理背包、管理物品 |

动作直接使用名称，取消每项重复的“打开”按钮。窄窗口允许组内换行。组队、解散和整理仍走原有检查与任务流程，管理物品仍进入既有编辑功能。

### 自由点击、角色与窗口、标定及设置

采用相同字体、按钮、边距和状态规则，保留现有清单编辑、排序、截图、标定、尺寸组、登录档案、设置与关于能力。角色与窗口页保留专属的尺寸 / 启动功能；唤出和全关统一使用顶栏入口。

### 日志与浮层

日志为右侧全高区域，默认宽度约占导航以外可用工作区的三分之一，允许拖动调整并记忆偏好；上下限依据实际字体和控件最小尺寸计算。原 236 像素参考宽不再作为修正验收目标。侧栏是全局共享消息流，详情见[全局日志行为](specs/15-global-log-behavior.md)。

可用宽度不足时，日志从右侧全高覆盖展开，业务页面不被强行压窄。顶栏全局按钮行及必要停止操作处于可达层，覆盖内容对其让位，不能遮挡“唤出 / 全关 / 日志”和急停。使用顶栏同一日志按钮或 Esc 收起，不保留面板内重复收起按钮或折叠轨第二入口。收起后焦点返回日志按钮，未读警告 / 错误由该入口表达。宽窗恢复后恢复原有展开与宽度偏好。连续日志正文使用正常可读文字，时间为次要信息，不把日志做成逐条卡片。

标定中心交互优化已由用户移出本轮，保留现有入口、项目组织与框选保存流程；本轮只接受统一字体和按钮样式带来的外观修正。先前讨论的直接展示、缺失项引导、逐项预览确认及连续标定不作为当前实施要求。既有业务见[通用标定契约](specs/15-common-calibration.md)。

配置浮层使用白色表面、清晰标题、关闭按钮与原有校验 / 保存流程。停止中、缺少标定、无目标、保存失败等状态直接表达结果，不能以颜色代替文字。

## 6. 实施与验收原则

生产实现复用 Qt Widgets、现有主题语义、任务服务与 signal/slot；不引入 Web 前端、QML 或 Fluent Widgets 依赖。HTML 原型只作为视觉来源，预览底栏、模拟按钮、占位文案均不进入正式产品。

验收优先保证文字与操作完整，再核对颜色和间距。在 1120×720、800×640 及 Windows 100%、125%、150%、200% 缩放下检查：任务标签、完整清单、固定操作栏、长角色名、日志侧栏 / 覆盖层和常驻窗口按钮。

自动检查使用现有 Qt 主窗口与临时配置，防止回归；最终由用户在 Windows 真机验证显示、缩放、唤窗、全关确认与任务启停。HTML 预览通过不等于生产 Qt 或真实游戏验收通过。

## 实施护栏

- 使用 PySide6 Qt Widgets，复用现有 Python 核心、任务、配置及 signal/slot；不新增 Web UI、QML 或状态管理框架。
- 默认演练、急停、输入保护、窗口身份和运行目标快照保持兼容；所有配置写入继续走原有保存护栏。
- 后续 Git 提交信息使用中文；每次实现只更新相关业务契约与实际验收结果。
- 从项目根运行统一回归：`python -m unittest discover -t . -v`，使用测试包的真实配置隔离。最终界面由用户在 Windows 真机验证。

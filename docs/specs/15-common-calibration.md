# 通用标定与活动逐项覆盖

## 行为

- 标定中心新增通用入口；宝图、运镖、秘境、蹈海去可逐项使用通用值或专属覆盖。
- 通用目录统一定义主识别区、活动列表、战斗标志、参加、日常活动、确认、确定、取消。各任务通过 `BINDINGS` 声明适用项；确认和确定是不同元素，取消暂未绑定业务。
- 现有非空活动标定自然视为专属覆盖，不移动图片、不挑选活动图片充当通用图。
- 日常活动旧共享模板仅在新通用模板未设置时作为通用兼容来源，各活动仍可单独覆盖。
- `恢复通用` 只清除当前项的专属值和尺寸指针。`设为整窗检测` 写入明确覆盖，不代表继承。
- 通用修改实时影响继承项；任务启动时继续使用已有运行配置快照。损坏的专属图保持专属来源，由展示和启动检查报告，不静默回退。

## 数据与入口

`tasks.common.regions/templates` 保存公共值。活动保留原有字段，通过统一目录映射到公共身份，兼容现有模板路径和任务接口。

每项尺寸分别写入 `regions_calib` / `templates_calib`。`calibration_modes.<group>.<key>` 使用 `override` / `inherit` 区分明确覆盖和继承，兼容没有模式的旧配置。尺寸组删除时同时清理区域和模板指针，保留图片。

- `core/calibration.py`：目录、绑定、只读解析、来源、尺寸、草稿更新和写入路径隔离。
- `effective_task_config` 仅供展示/自检/运行读取；禁止把继承后的配置整体写回活动。编辑仍使用 `config.task_config` 原始配置及独立草稿。
- `core/calibration_runtime.py`：按实际资产来源转换模板尺度、区域及匹配坐标，只缩放内存截图。
- `TaskContext.task_cfg`、活动页导航、四个活动及 Qt 摘要统一读取最终标定。
- `core/list_row.locate_card` 支持卡片和参加按钮分别标定尺寸，保持同帧、同卡、右侧最近按钮几何绑定。
- 窗口尺寸变化时同时兼容原始像素匹配；尺寸组不代表游戏内控件一定同比缩放，旧模板无需因外壳/DPI 尺寸记录不同而重标。
- 参加搜索限制为从条目中心起的一个卡片跨度，列数只估相对跨度、不作为绝对分列边界；本卡按钮缺失或低分时不借用邻卡按钮，重叠和左侧候选不得回退成为点击目标。
- Qt 编辑器显示来源和逐项尺寸，支持单独标定与恢复通用；图片提交复用原有保存失败回滚。

通用和活动图片使用不同路径；同名的活动日常按钮包含任务名称。路径被手工设成共用时，重标定另选独立路径。每份资产仍只有一张图，不按尺寸复制。

## 验证

新增纯配置、合成像素、Qt 临时资产和摘要接线测试，覆盖逐项优先级、实时继承、恢复、整窗语义、尺寸来源、旧配置兼容、图片隔离、保存失败回滚和卡片绑定。

```powershell
python -m unittest discover -t .
```

自动测试不操作真实游戏。最终仍需在游戏内演练确认模板裁剪与实际界面一致，以及常用窗口尺寸下的命中情况。

本次验证：全量 718 项测试通过（新增 51 项），Python 编译检查通过；已离屏渲染检查通用页及活动编辑器，默认窗口宽度下来源列完整可见。

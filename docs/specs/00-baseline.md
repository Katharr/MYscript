# Spec 00：记录 UI 性能基线

## 目标

在改 UI 前得到可重复的基线，避免凭体感判断迁移效果。

## 只做这些

- 新增一个临时或测试脚本，测量：冷启动到主窗可操作、首次打开页面、重复切页、展开完整界面、恢复悬浮窗。
- 记录进程内存、主线程卡顿最长间隔、各动作总耗时。
- 输出 `docs/specs/baseline-YYYYMMDD.md`。

## 测量规则

- 使用同一台 Windows 机器、同一配置、同一窗口数量；无游戏窗口和有 3 个窗口各测一次。
- 每项预热 1 次，再测 5 次，记录中位数和最大值。
- 不修改 `config.json`、模板、任务代码或默认启动入口。

## 验收

- 基线文档包含环境、测试步骤、5 次原始数据、中位数、最大值。
- 原有测试全部通过：`python -m unittest discover -t . -v`。
- 若 GUI 无法自动化测量，记录人工计时方法，不伪造数字。

## 不做

- 不在本阶段优化代码。
- 不安装 PySide6。

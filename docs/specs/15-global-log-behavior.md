# 全局日志行为契约

状态：保留现有日志业务行为。3.0 的位置、尺寸与外观以[视觉规范](../视觉设计规范.md)为准；早期右侧日志布局提案已归档。

## 消息与呈现

- 所有页面共享一个全局消息流；切页不清空日志或来源筛选，不重复消费消息。悬浮信息继续复用同一消息出口。
- 保留来源筛选、清空、选中复制与连续文本滚动；长消息自然换行。来源与时间为次要信息，级别同时用文字表达。
- 接收时间在消息入队时记录并缓存；筛选、换肤与重绘不重新生成，不重复添加已有时间戳。
- 缓存上限沿用 5000 条，展示元数据随消息一起淘汰。清空同步清理数量与未读状态。

## 跟随与未读

- 默认跟随最新；用户向上滚动或选择文本时暂停跟随，追加消息不改变阅读位置。
- 回到末尾或点击新消息提示后恢复跟随。
- 日志收起时保留未读警告 / 错误提示。普通日志与错误均不强制展开，也不抢占任务区。

## 布局状态与线程

- 首次使用默认展开，后续恢复用户的展开与宽度偏好；窄窗自动覆盖展示不覆盖宽窗偏好。
- 顶栏同一日志按钮负责展开与收起，取消面板内重复收起按钮及折叠轨第二入口，支持 Esc；展开状态与按钮状态同步，收起后焦点返回该按钮，未读警告 / 错误在该入口呈现。
- 日志与应用客户区同高，默认约占导航以外工作区三分之一宽，支持拖动及偏好恢复。窄窗全高覆盖展开，不强行压窄业务页面；全局按钮行与必要停止操作始终可达，覆盖内容对其让位。角色条下方的固定窄栏不再作为验收目标。具体视觉以[视觉规范](../视觉设计规范.md)为真源，实施范围见[修正方案](22-ui-v3-polish.md)。
- 界面设置仅保存展示状态；业务任务与标定配置继续使用原配置保存护栏。
- 后台线程不操作 QWidget，消息经原有 Qt signal/slot 交回主线程。

## 验收

复用现有 Qt 全局日志与右侧日志回归，覆盖筛选、清空、复制、阅读位置、缓存淘汰、未读、窄窗恢复和消息不丢失 / 不重复。3.0 尺寸按新视觉规范重新验收，旧像素断言只在明确替代的布局要求上调整。

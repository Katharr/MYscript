# Spec 06：迁移秒装备页

## 目标

迁移秒装备页，保留模板缩略图、数量设置和演练/实战边界。

## 修改范围

- 新增 `mhxy/qtui/sniper_page.py`。
- 复用 `widgets.load_thumb` 的读取约束；必要时新增 Qt 图片缓存小函数。
- 不改 `tasks/sniper.py`、模板路径和购买流程。

## 实现

- 商品清单使用 Qt model/view；只在模板路径或文件时间戳变化时刷新缩略图。
- 显示购买数量、商品模板、区域状态、成功数量和当前状态。
- 开始/停止通过 `TaskPage`；默认演练。
- 模板缺失时显示“未标定”和入口，不在主线程读取大图。

## 验收

- 中文模板路径可显示；模板不存在不抛异常。
- 重复切页不重复加载图片。
- 实战/演练、购买计数和停止结果与旧测试一致。
- `test_sniper.py` 与全量测试通过。

# Spec 05：迁移宝图、运镖、秘境页

## 目标

迁移三类活动页，复用同一页框架和活动卡片布局。

## 修改范围

- 新增 `mhxy/qtui/treasure_map_page.py`、`escort_page.py`、`secret_realm_page.py`。
- 复用 `core/list_row.py`、现有任务类和 `TaskPage`。
- 不改识别阈值、`locate_card`、窗口轮转或任务步骤。

## 实现

- 页头：任务名、游戏连接、演练/实战状态、开始/停止。
- 常用参数直接显示；标定入口和完整状态集中在一张卡片。
- 活动列表默认两列；参加按钮定位继续走 `core.list_row.locate_card`。
- 参数写回现有任务命名空间，旧配置可直接加载。

## 验收

- 三页均能选择窗口、查看标定状态、开始/停止。
- 宝图“已有宝图”、运镖次数/时限、秘境轮数/时限行为不变。
- 演练模式不产生真实输入；活动卡片顺序和参加定位测试通过。
- 相关任务测试和全量测试通过。

## 不做

- 不合并三种任务配置。
- 不重写 `core/list_row.py` 或任务识别逻辑。

# Spec 10：迁移设置、关于、日志抽屉和悬浮信息条

## 目标

补齐非任务页面，并把运行日志收敛为 Qt 底部抽屉和可选悬浮条。

## 修改范围

- 新增 `mhxy/qtui/settings_page.py`、`about_page.py`、`float_log.py`。
- 复用 `gui/shortcuts.py`、`core.emergency`、`core.config`、`RuntimeService`。
- 不修改快捷键判定、急停角和输入后端。

## 实现

- 设置页只编辑现有字段，保存仍走 `save_config`。
- 急停热键、失控角、外观和速度参数可读取/保存；输入不合法时拒绝写盘。
- 日志抽屉支持展开、收起、清空和按来源查看；悬浮条显示运行名、状态、停止、展开。
- 悬浮条关闭只恢复主窗，不等同退出程序。

## 验收

- 快捷键配置解析与旧测试一致。
- 任务运行时急停仍能停止全部任务。
- 日志长时间运行不会无限增长或阻塞 UI。
- `test_app_state.py`、`test_runtime_entry.py`、`test_gui_boundaries.py` 和全量测试通过。

## 完成记录（2026-10-16）

- 新增 Qt 设置页和关于页，设置复用 `gui.shortcuts` 的热键组合/解析及原速度范围；完整校验后重新读盘合并，再调用 `save_config`，错误内联提示，不写入非法值。
- 主窗口统一消费 `RuntimeService` 日志，每个 60ms 周期最多 64 条；底部抽屉支持展开、收起、清空和来源筛选。保留最近 5000 条记录，显示最多 5000 行，单条显示最多 4096 字符，收起时只更新缓存。
- 新增可选悬浮信息条，显示运行名、状态和最新日志，提供停止、展开及置顶；关闭只恢复主窗，偏好沿用 `float_log.geometry/topmost` 字段。主窗隐藏后仍轮询急停，取消启动与停止统一走原运行入口。
- 配套文件：`qtui/window.py` 负责页面注册、全局日志分流、悬浮生命周期与设置刷新；`qtui/theme.py` 支持深浅外观并同步已有页面和后续对话框；`qtui/log_panel.py` 补来源筛选及有界、增量刷新。
- 配套文件：`core/runtime.py` 和 `core/runner.py` 仅将统一事件队列和旧兼容日志队列限制为最近 5000 条，满时丢弃最旧日志，生产线程不等待 UI；不改变任务、识别、输入、配置、安全默认值和运行互斥业务。
- 新增 `tests/test_qt_settings_log_float.py`：16 项覆盖热键兼容、非法值拒写、最新配置合并、写盘失败、外观切换、筛选与多行日志淘汰、日志积压、悬浮恢复/退出及隐藏主窗急停。测试配置、窗口设置和检测均隔离。
- 局部离屏测量：缓存满 5000 条短日志时展开约 22ms，筛选状态下一批追加 64 条约 4ms；这是本阶段日志控件的开发验证，不代替 spec11 的整机性能验收。

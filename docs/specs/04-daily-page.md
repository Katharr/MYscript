# Spec 04：迁移日常一条龙页

## 目标

把一条龙迁移到 Qt，明确本次将执行、将跳过和缺少条件。

## 修改范围

- 新增/修改 `mhxy/qtui/daily_page.py`。
- 必要时只适配 `mhxy/tasks/daily.py` 的只读状态计算；不改执行流程。
- 复用 `core.config.task_config`、`tasks.daily.CHAINABLE`、任务 `preflight`。

## 实现

- 只显示 `CHAINABLE`：宝图、运镖、秘境、副本；秒装备不得加入一条龙。
- 每行显示启用、顺序、模式和本次结果：`将执行`、`演练将跳过`、`缺少标定`、`未选窗口`。
- 保留拖动排序和总时限；保存字段结构不变。
- 启动前在后台计算摘要，启动后调用现有 DailyTask。

## 验收

- 顺序和开关写回 `tasks.daily.steps`。
- 演练任务明确显示跳过，并与旧执行结果一致。
- preflight 失败不会点击游戏；页面能显示具体缺失项。
- 相关 `test_daily_*` 与全量测试通过。

## 不做

- 不把子任务参数复制到一条龙页。
- 不新增任务类型或改变跳过策略。

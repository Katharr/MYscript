# 梦幻西游 · 时空辅助助手

Windows 桌面 GUI 辅助工具。项目通过“截屏 + OpenCV 图像识别 + 模拟鼠标/键盘输入”操作《梦幻西游：时空》PC 客户端，不读内存、不注入游戏进程。

## 安装部署

### 运行环境

- 系统：Windows 10/11。
- Python：建议 Python 3.10 或更高版本，安装时勾选 `Add Python to PATH`。
- 游戏客户端：先确保《梦幻西游：时空》Windows PC 客户端能正常打开、登录，并保持脚本运行期间窗口尺寸稳定。
- 网络：首次安装 Python 依赖时需要联网。
- 权限：建议用管理员权限运行本工具。很多游戏客户端以管理员权限运行，脚本如果权限较低，Windows 可能会拦截鼠标输入。

### 从源码运行

1. 获取项目后进入项目根目录，也就是包含 `start.py`、`requirements.txt`、`启动.bat` 的目录。
2. 首次运行任选一种方式：
   - 双击 `启动.bat`。
   - 或在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python start.py
```

3. `启动.bat` 会检查本机是否能找到 `python`，然后执行 `python start.py`。
4. `start.py` 会检查依赖是否齐全；缺依赖时自动执行 `pip install -r requirements.txt`，依赖齐全后启动图形界面。

如果双击后没有界面，先在 PowerShell 里运行 `python start.py`，这样能看到依赖安装或启动报错。

### 打包成 exe 交付

项目内置 PyInstaller 打包脚本，适合把工具发给不看源码的使用者。

打包前先安装 PyInstaller：

```powershell
python -m pip install pyinstaller
```

然后任选一种方式打包：

- 双击 `打包工具\打包.bat`。
- 或在项目根目录执行：

```powershell
python 打包工具\build.py
```

打包完成后会生成类似下面的交付目录：

```text
发布\梦幻秒装备_v2.2\
  梦幻秒装备.exe
  config.json
  templates\
```

交付给别人时要发送整个文件夹，不要只发 exe。`config.json` 保存真实配置和标定结果，`templates\` 保存识别模板图，缺任意一项都会导致任务无法正常识别。打包产物默认把各任务切回演练模式，使用者需要在 GUI 里自行确认后再开启实战。

### 关键目录和文件

```text
项目根目录\
  启动.bat                 一键启动入口
  start.py                依赖检查、提权、启动 GUI
  requirements.txt        Python 依赖
  config.json             当前真实配置，含窗口、任务参数、标定结果
  config.example.json     配置示例
  templates\              标定生成的模板图
  captures\               运行中保存的命中/卡住截图
  mhxy\
    core\                 配置、窗口、截图、识别、输入、任务上下文
    tasks\                可注册任务：秒装备、宝图、运镖、秘境、副本等
    gui\                  主界面和各功能页
    tools\                标定等辅助工具
  打包工具\               PyInstaller 打包脚本和说明
  发布\                   打包后的交付目录
```

源码运行时，`config.json`、`templates\`、`captures\` 都在项目根目录。exe 运行时，这些数据会放在 exe 同级目录。

## 使用说明

### 首次使用流程

1. 启动游戏客户端，并登录要操作的号。
2. 启动本工具：双击 `启动.bat` 或运行打包后的 `梦幻秒装备.exe`。
3. 打开 GUI 后先进入对应任务页，点击 `选择窗口`。多开任务需要选择多个游戏窗口；组队相关任务还需要指定队长。
4. 点击任务页里的 `标定`，按向导框选区域和按钮。标定结果会写入 `config.json`，模板图片会写入 `templates\`。
5. 保持默认的演练模式运行一次。演练模式只识别和记录日志，不执行真实购买、使用、出售、参加活动等关键动作。
6. 查看右侧全局日志和 `captures\` 截图，确认识别准确、流程正确。
7. 确认无误后再打开对应任务页的 `实战模式` 开关并运行。

### 全局停止方式

- 点击当前任务页的 `停止` 按钮。
- 按全局急停热键，默认是 `Ctrl + Alt + F12`。
- 任务运行时把鼠标甩到屏幕角落触发失控急停，默认是右上角。

急停热键和失控急停角落可以在 `设置` 页修改。

### 通用 / 工具页

`通用 / 工具` 页放跨任务共享能力：

- `选择窗口/队长`：选择单开或多开窗口，并指定队长。
- `标定（组队）`：标定创建队伍、申请、同意、退出队伍等共享模板。
- `标定队长ID`：保存队长 ID 图，队员通过它在好友列表中定位队长。
- `一键组队`：按已选窗口自动组队。
- `一键解散`：让已选窗口退出当前队伍。
- `还原尺寸`：把所选窗口恢复到标定时记录的基准尺寸。
- `标定（整理背包）`、`管理物品`、`一键整理背包`：配置需要使用、丢弃、商会出售或摆摊出售的物品。
- `自动整理背包`：开启后，走多开轮转的任务会定期检测背包满图标，命中后自动整理。

### 秒装备

用途：盯市场货架，目标装备出现后立即执行购买流程。

基本步骤：

1. 进入 `秒装备` 页，点击 `选择窗口`。
2. 打开游戏市场到对应货架入口。
3. 点击 `标定 / 加装备`，按向导框选：
   - 左侧商品类别按钮。
   - 右侧商品入口。
   - 购买按钮。
   - 确认按钮。
   - 要监控的装备模板图。
4. 先保持演练模式，点击 `开始秒装备`。
5. 看日志和 `captures\`，确认模板命中准确。
6. 再打开实战模式运行。

当前秒装备是“命中即抢”，不做 OCR 比价。模板建议只框装备本身，不要把价格文字框进去。

### 宝图

用途：自动开活动、接宝图、挖宝、领奖。支持多开轮转。

使用要点：

- 在 `宝图` 页点击 `选择窗口`，多开时选择多个号。
- 点击 `标定`，按向导标定活动列表区域、背包列表区域、宝图入口、参加按钮、对话选项、战斗标志、下一张、藏宝图物品等模板。
- 如果已经有藏宝图，可以在页面里选择跳过领取阶段，直接从背包挖图。
- 默认演练只做识别自检；实战才会真开活动、真用藏宝图、真领奖。

### 运镖

用途：自动开活动、参加运镖、押送普通镖银，并按设置循环押满次数。支持多开轮转。

使用要点：

- 在 `运镖` 页选择窗口。
- 标定活动列表区域、运镖卡片、参加按钮、押送普通镖银、确认按钮、运镖中标志、战斗标志等。
- 设置押镖次数和时间上限。
- 演练确认识别后再切实战。

### 秘境降妖

用途：自动开活动、参加秘境、选择副本、继续挑战，并在战斗/失败/超时状态间推进。支持多开轮转。

使用要点：

- 在 `秘境降妖` 页选择窗口。
- 标定活动列表区域、秘境卡片、参加按钮、秘境选项、进入、确定、继续挑战、挑战、进入战斗、离开、失败等模板。
- 设置每号运行轮数和时间上限。
- 演练模式只识别流程；实战才会点击进入和挑战。

### 刷副本

用途：从已注册副本中选择一个执行。目前项目内置 `蹈海去·50`。

使用要点：

- 先在 `通用 / 工具` 页完成组队相关标定，除非你在副本页勾选 `已组队`。
- 在 `刷副本` 页选择窗口、队长和副本。
- 点击副本页 `标定`，标定当前副本自己的活动入口、参加、选择副本、进入、跳过剧情、任务日常、任务条目、马上传送、对话选项、小闹钟等模板。
- `已组队` 表示跳过组队流程，直接由队长开刷。
- `跑完解散队伍` 会在副本结束后调用通用解散流程，需要先标定退出队伍按钮。

### 日常一条龙

用途：把已有任务按顺序串起来跑。当前候选包括宝图、运镖、秘境降妖、刷副本等会自然结束的任务；秒装备不在一条龙里，因为它是持续监控任务。

使用要点：

- 在各子任务页先完成标定和演练/实战设置。
- 在 `日常一条龙` 页勾选任务并调整顺序。
- 多开、窗口选择、演练/实战、标定和参数都沿用各子任务自己的设置。
- 缺标定或缺窗口的子任务会在运行时提示或跳过。

### 设置页

常用设置：

- 游戏窗口标题关键字：默认匹配 `梦幻西游`。
- 游戏进程名：默认 `MyGame_x64r.exe`，客户端进程名变了要同步修改。
- 输入后端：默认 `sendinput`。如果游戏内无响应，可尝试以管理员权限运行，必要时再切换后端。
- 急停快捷键：默认 `Ctrl + Alt + F12`。
- 失控急停角落：默认右上角，可关闭。
- 拟人化速度、抢货速度、点击随机半径、间隔抖动等参数。

也可以直接编辑 `config.json`。所有任务配置都在 `tasks.<任务名>` 下；编辑前建议先备份。

## 常见问题

### 找不到游戏窗口

- 确认游戏客户端已经打开。
- 在设置页检查窗口标题关键字和进程名。
- 多开时点击 `选择窗口` 重新枚举。

### 鼠标在桌面有效，但切到游戏后不动

- 以管理员权限运行本工具。
- 确保工具权限不低于游戏客户端权限。
- 仍无效时，在设置页尝试切换输入后端。

### 识别不准、误点或漏点

- 重新标定对应任务。
- 保持游戏窗口大小和标定时一致，必要时用 `还原尺寸`。
- 模板尽量框独特区域，不要框太大。
- 在演练模式看日志和 `captures\` 截图，再决定是否调整 `match_threshold`。

### 换电脑后不能直接跑

标定坐标依赖窗口尺寸、缩放和 UI 布局。换电脑、换分辨率、换窗口尺寸后，建议至少重新选择窗口并重新标定关键区域和模板。

### 打包后别人运行不了

- 确认发送的是整个 `发布\梦幻秒装备_vX.Y\` 文件夹。
- 确认 `梦幻秒装备.exe`、`config.json`、`templates\` 在同一级目录。
- 首次运行 UAC 弹窗要允许。
- 如果识别全失效，大概率是模板或配置没有随包，或对方窗口尺寸与标定尺寸差异过大，需要重新标定。
